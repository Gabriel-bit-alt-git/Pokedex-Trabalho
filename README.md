## Nome do Integrante [Individual]

## Tema escolhido

Sistema de gerenciamento de Pokédex no universo 
de Pokémon, desenvolvido para fins acadêmicos.

## Pré-requisitos + Como executar

- Node.js
- MySQL Server
- MySQL Workbench
- Git ou GitHub Desktop

1. Baixe o zip do código fonte nos lançamentos.
2. Abra a pasta do projeto no Visual Studio Code.
3. Execute `npm install` no terminal.
4. Execute o arquivo script.sql no MySQL Workbench e crie as tabelas.
5. Renomeie o arquivo ".env.example" para ".env", e preencha sua senha.
6. Configure as variáveis de ambiente conforme suas credenciais do MySQL:

`.env`
- DB_HOST=localhost
- DB_USER=root
- DB_PASSWORD=[sua_senha]
- DB_NAME=bdnode
- PORT=3000

7. Baixe o .zip com as imagens providenciadas, ou utilize as suas.
8. Execute `npm start` no terminal do VS Code.

## Acesso
